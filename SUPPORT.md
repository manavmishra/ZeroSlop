# Support

## Setup and usage

Start with the [README](README.md), the [worked examples](examples/), or the
[hosted MCP guide](https://zero-slop.ai/mcp/).

- Ask a usage question in [GitHub Discussions](https://github.com/manavmishra/ZeroSlop/discussions).
- Report a reproducible bug with the [bug form](https://github.com/manavmishra/ZeroSlop/issues/new/choose).
- Report a scoring false positive with a short, redacted example. Do not post a
  confidential draft or a private voice profile.

## Security

Do not open a public issue for a vulnerability. Follow the private reporting
instructions in [`SECURITY.md`](SECURITY.md).

The local skill and hosted MCP have different data paths. Read the
[MCP privacy notes](https://zero-slop.ai/#mcp) before sending a sensitive draft to a remote
endpoint.
