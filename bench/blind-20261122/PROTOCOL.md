# Preregistered synthetic editorial-quality comparison, revision 2

Author and data owner: /root/benchmark_sealed_corpus, independent of implementation; no model/competitor implementation, patterns, scores or outputs inspected before freezing. Delivery-reviewer skill applies. All data are newly authored synthetic fictional scenarios and labels from one agent, not human truth, not an AI-provenance corpus.

Development: 24 drafts / 12 source groups. Held out: 60 drafts / 30 source groups. Each source has a clean draft and a counterpart with one unnecessary span; source groups never cross splits. Genres: social, email, PRD, research, technical, compliance, financial, commercial. All drafts are 120–200 whitespace-delimited words. Positive labels include missing-substance recommendations, contextual redundancy, and inflated or decorative filler. Clean controls include necessary formal language, substantive contrasts, quoted examples, literal identifiers, Unicode, uncertainty, and second-language wording. Balanced labels are a test design choice and do not estimate production prevalence.

Before unsealing, record a single final candidate revision, baseline revisions/versions, method settings, output schema, any paid/free limitations, and a SHA256 of each frozen artifact. Root must not inspect held-out text or labels until candidate frozen. No further candidate changes may be evaluated as confirmation on the same sealed set; later changes are development-only pending a fresh holdout. Freeze native default meter thresholds rather than tune them on either set. Report native meter comparisons separately from same-host editing workflow comparisons; a regex meter and a full rewriting service are different capabilities.

Primary detection unit: a draft. Positive if a method recommends removal/rewrite for editorial slop; uncertainty/abstention remains distinct and counts as missed positive for recall, not a clean positive. Recall = detected positives/30. Precision = true positives/all positive calls, undefined if no positive calls. Specificity and clean no-edit rate use the 30 clean drafts. Report clean flag rate and actual clean edit rate separately. Flagging a quoted example without identifying its quotation context is a false positive. A span hit additionally requires the finding to overlap at least half of the annotated target's characters; report span recall separately from draft recall. Do not invent precise spans for methods returning only a document score.

Editing: score removal of the annotated unnecessary proposition, not lexical deletion alone. Missing-substance cases may remove filler or ask for author-supplied specifics; invented actors, schedules, evidence, outcomes or commitments fail. Record partial removal separately. A successful positive edit removes the target, preserves source facts and immutable relationships, and respects voice constraints. Protected spans need semantic preservation, except literal identifiers/quotations/numbers must remain exact. An unchanged output is a positive removal miss and a clean no-edit success. Treat paraphrase without need as an edit, but assess damaging paraphrase separately. Report context loss by draft and by violated claim: changed quantity/unit, polarity, modality, condition, exception, temporal scope, causal status, uncertainty, identifier, quote, or voice. Context loss assessment must cite source/output spans and remain blinded to method names where feasible; subjective judgments need uncertainty notes. Data-owner labels are not an independent human assessment.

Paired comparison: keep source groups together. Report all confusion matrices and per-genre counts. Report candidate-minus-baseline recall, precision, specificity, clean no-edit rate, successful removal and context-loss rates. Use 10,000 paired source-group bootstrap resamples with seed 20261122 for percentile 95% intervals; precision samples with zero positives are undefined and must be counted rather than silently replaced by 0 or 1. For paired binary outcomes also report discordant group/draft counts and exact two-sided McNemar/binomial p-values, labeled exploratory across multiple competitors/outcomes. Groups, not the 60 correlated drafts, are the effective resampling units. Tiny per-genre samples are descriptive only.

Scoped gain screen (not a broad reliability claim): relative to the named current baseline, require at least +10 percentage points positive recall, precision no lower than baseline, clean no-edit >=29/30 and no lower than baseline by more than 1/30, zero observed source-claim losses, and successful positive removal no lower than baseline. If only detection is implemented, editing/context gains remain untested and must not be claimed. If precision is undefined, this screen cannot pass. To say a gain is statistically supported on this synthetic set, the paired 95% interval for the claimed improvement must exclude zero; otherwise say observed point improvement with inconclusive uncertainty. Report all failed gates. Zero observed context errors in 60 drafts does not prove zero risk. Do not use this screen alone to authorize publishing.

Limitations: one author and labeler, repeated genre context, repeated controls, one injected span per positive, paired drafting, small holdout, selection influenced by editorial task definition, no real customer or naturally generated model drafts, no human truth and no universal competitor coverage. Test conclusions must remain scoped accordingly. Further transfer evidence should use independent human-labeled drafts and unseen source groups.
