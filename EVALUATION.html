Zero Slop: what survived testing

01The finding that matters most

No human raters took part. Each pass used five fresh LLM judge runs from the same model family, one for each ten-draft packet. The model saw the writing brief, source draft, factual inventory, and four rewrites behind shuffled labels. It rated human-likeness, voice, fidelity, craft, and platform fit, flagged fabrication, and selected the best and worst version.

The first pass gave Zero Slop 32 of 50 best-picks. Repeating the pass with the same text and label mapping but fresh model runs produced 23 of 50. Cohen's kappa on the winner choice is 0.12, with per-item agreement at 52 percent. The ratings are unstable enough that a single-pass result should not be treated as a ranking.

The public harness preserves the packets, shuffle key, raw scores, and aggregation code. It does not preserve the exact judge model and version, inference settings, or full evaluation prompt, so the LLM ratings cannot be reproduced exactly.

What survives replication. Pooled across 100 verdicts: Zero Slop 55, blader/humanizer 40, petergyang/no-ai-slop 5, isatimur/de-slop 0. Zero Slop wins the plurality against a 25 percent chance rate (p = 1.7 × 10-10). Against blader specifically it is not statistically separable (p = 0.15). The ranking order held in both runs; only the margin moved.

03Where the LLM ratings disagreed with the meter

de-slop received 27 worst-picks in the first LLM pass even though it removed many surface tells. Surface cleanliness and writing quality are different measurements; neither the meter nor the model ratings should stand in for the other.

04The adversarial audit

A red-team agent spent 36 tool-calls attacking the scorer. It found six real vulnerabilities, all now fixed and regression-tested.

  • Contraction-locked regexes. Expanding "it's" to "it is" dropped a 20-tell paragraph from 100 to 9.5 — while the skill's own register rule told rewriters to add contractions. Following the skill raised the score; evading it hit the floor. Eighteen patterns now match both forms.
  • Backtick laundering. Inline code spans were stripped before scoring, so wrapping slop in backticks hid it completely. Only the backticks are removed now.
  • Unbounded length normalisation. The same 20 tells passed the gate at 2,437 words, while one tell in a 7-word tweet scored 100. The window is floored and an absolute-weight term added.
  • Invisible edgy-slop. Text built entirely from the skill's own banned over-corrections scored 18.2 — the gate was certifying the failure mode the skill documents. Four over-correction patterns added.
  • Punctuation convicting alone. An uncapped em-dash term scored the Gettysburg Address at 88.9. Formatting and register signals now require lexical corroboration, which finally implements the "clusters convict, singles don't" rule the scorer stated but never enforced. Gettysburg now scores 29.6.
  • Self-dealing in the learning loop. Step 6 let an executing model lower a weight with no rule against doing so to pass the draft under review. Explicitly forbidden now.

Documented and still open, by design or by scope: hollowness is invisible to any regex, which is why the judgment pass exists; non-Latin scripts score unconditionally clean; and dialogue, poetry and citation-heavy pages remain out of scope.

05Takeaways

  • Report the disagreement. The same rewrites produced materially different best-pick counts in two LLM passes.
  • Keep the measurements separate. The meter is repeatable but narrow. The LLM ratings cover broader qualities but were unstable.
  • Check for deletion. Word count helps reveal a rewrite that lowers its tell count mainly by cutting, but preserved length does not prove preserved substance.
  • Use a larger external corpus next. Fifty synthetic drafts from the project author cannot support a general accuracy or quality claim.
  • Turn failures into tests. A fabricated feeling flagged in both LLM passes, a scorer that convicted Lincoln, and a scoring-evasion bug each led to a regression check.
